# 客户端直连加速接入（2026-11-02）

## 已实测

Mac 的 gdirect 数据连接使用 IP_BOUND_IF 绑定物理网卡 en1，绕过本机 TUN 和 HTTP/SOCKS 代理，不经过网盘服务器。Google GTS 证书校验开启，排除第三方中继；下载 8 连接。

| 文件 | 上传至 Google 可用 | 下载并校验 |
| --- | --- | --- |
| 30,000,001 字节 | 35.139 秒 / 0.8537 MB/s | 9.571 秒 / 3.1344 MB/s |
| 1,000,000 字节 | 3.815 秒 / 0.2621 MB/s | 4.219 秒 / 0.2370 MB/s |

30 MB 下载比先前网页 Drive 路径快约 9.9 倍，上传比网页服务器存储快约 3.25 倍。这是单次观测，不是带宽保证。第一个端点连接失败后，使用已核验端点缓存的自动选择完成传输。合成测试文件已清理，大小、MD5/SHA-256 均匹配。

## 已上线的接法

1. 在这台 Mac 安装仅监听 127.0.0.1 的加速组件，网站自动检测。上传文件先在本机分片落地，随后由 gdirect 直传 Drive；下载由 gdirect 8 连接直达本机。
2. 保留网页的分片、暂停与继续机制。组件未运行的设备继续使用既有服务器入口。
3. 加速组件以单独的随机密钥向服务器换取短期访问令牌，令牌只进入本机 gdirect 子进程环境。网页从不收到 Google 写令牌，刷新令牌仍只存在服务器。
4. 服务器负责核对上传的 Drive 文件归属、名称和大小，随后更新现有文件映射。既有备注、删除、列表和旧服务器文件保持兼容。
5. 本机大文件缓存和下载写入外置盘 Inbox，凭据写入应用默认配置目录并设为 0600。只绑定加速子进程，不修改系统代理、TUN 或默认路由。
6. ≤30 MB 暂时保留服务器存储：1 MB 的服务器上传 8.430 秒、下载 3.035 秒；直连上传更快、下载稍慢。已向用户提供全部切 Drive 的选项，尚未收到变更选择。

## 验收范围

部署前核对语法；上线后仅做一个代表性文件的网页 → 本机组件 → Drive → 本机下载内容校验与清理。确认组件状态、服务进程资源和旧文件入口兼容。结果与实际限制写入 HANDOFF.MD。

## 实际验收结果

- 原生上传协议经本机分片、gdirect、服务器文件归属验证完成，正式列表显示 Drive 文件。初次因 nginx 未放行新接口停止，修复后续传同一份本机分片；完成阶段 23.503 秒，该时间不含最初的本机分片接收。
- 已发布网页显示“直连加速已连接”，实际点击该合成文件的“加速下载”，页面显示本机保存位置；30,000,001 字节大小与 SHA-256 一致。
- 测试文件、下载副本、上传分片和本机完成记录均已清理，正式列表前后均为 127 项。删除后本机完成记录的失效也已验证，后续重新上传同名文件不会复用失效的完成状态。
- broker 缺失配对密钥为 403；带浏览器 Origin 即使携带正确密钥也为 403。本机 gdirect 已保存 Google 账号数为 0。
- Python/JavaScript 语法、nginx -t 均通过；后端 active、自动重启计数 0。最终空闲服务器服务内存 15,818,752 字节（约 15.1 MiB）；本机组件 RSS 17,936 KiB（约 17.5 MiB）、CPU 0.0%。这是空闲快照，未做负载测试。
- 原始记录：`/Volumes/Samsung SSD/page/202610/outputs/20261102-netdisk-physical-direct/`。

## 使用与已知限制

- 当前加速适用于已安装组件的这台 Mac。网页自动检测，点击“直连加速已连接”可关闭；未运行组件的设备继续使用服务器通道。
- 本机组件安装目录：`/Volumes/Samsung SSD/Applications/simple-netdisk-accelerator/`；仅监听 `127.0.0.1:18743`。Google 数据连接强制绑定 en1，网卡不可用时传输失败，不静默转为代理。
- 下载文件位于 `/Volumes/Samsung SSD/Inbox/无痕同步下载/`；上传失败的临时分片保留在 SSD Inbox 下，以便继续上传。
- macOS 拒绝 LaunchAgent 读取外置盘脚本，因此没有设置开机自启。当前组件已运行；重启 Mac 后在 Finder 双击安装目录的 `启动加速.command`，再点网页“连接加速”。失败的 LaunchAgent 已移除。
- 配对配置位于 `~/Library/Application Support/simple-netdisk-accelerator/config.json`，权限 0600，包含本网盘密码和配对密钥。不要上传到 GitHub。Google 刷新令牌没有复制到本机。
- 公网 nginx 需单独放行新接口；公开片段为 `backend/nginx-accelerator.conf`。只允许站点 Origin 的本机接口与拒绝浏览器 Origin 的服务端 broker 是两层不同的边界。
